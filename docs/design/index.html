Tansu workflows 箪笥

Every flow in the app, drawn in Kiri at the Galaxy S24's 360 × 780 dp. Tansu opens on the phone's storage, and each server you add becomes a drawer beside it. There's no sign-in, and every job shows what it's doing, how far it got and how long is left.

The language: Kiri → The three directions →

How it fits together

Browse
  • Drawers: the phone, then each server
  • Folders and files, list or grid, sort and search
  • Select to cut, copy, share, rename or delete
  • Pictures, videos and PDFs open in place
Transfers
  • Every copy, move, delete and save
  • What, how far and how long
  • Pause, resume, cancel and retry
  • A summary when each one ends
Settings
  • Theme and dynamic colour
  • How Browse sorts and shows files
  • Servers: add, edit and remove
  • About, and new versions from GitHub
Ways in
  • Android's share sheet: save to a drawer
  • A job's notification: that job
  • First run: All files access, once
  • An update: Settings › About
